# Shared signature position and membership facts

AS-W02 / IN_PROGRESS. SnapshotSignatureIndex borrows frozen typed input and its
canonical atom key owner. It owns managed scratch and fixed control256B. It is a
partial fact inspector, never complete signature admission or CheckedSnapshot.
References, types, parameter modes/bindings, ownership and capabilities remain
independent validation obligations.

Each exact (LIST source, Parameter/ResultSlot kind) is folded once, including bad
lists. Membership retains every canonical INTEGER position. Adjacent integer order
and exact equality to the actual long row ordinal decide two predicates. The
integerEqualsNatural helper never narrows input INTEGER, creates expected decimal
String/BigInteger, or interns per-query tuples. Cached sign/length reject giant
positions; at most two packed16-character leaves compare an ordinal of at most19
digits. Long boundaries/overflow are explicit.

Open inventories report unordered rows. Closed inventories report unordered OR
noncontiguous rows, once each. One bad-row payload can participate in two separately
ordered indices, preventing repeated scans of closed-only errors for open owners.
Only a completed fold becomes queryable. Invalid-list counts are reusable required
facts, not validity. Reports count occurrences in bulk for each owner and retain
only the prefix permitted by remaining capacity. Zero capacity never selects an
issue cursor. Counts continue exactly after retention fills. Source anchors stay
internal until a separate diagnostic renderer binds external IDs/paths.

checkEntry reports both inventory position sequences, then absent ParameterInitial
positions as I-02 using the entry ID as owner. Initial membership remains independent
of bad position order/contiguity. Initial-state iteration is per requested Entry;
shared owner/context annotation summaries and the complete Validator are pending.

Primitive work is O(distinct rows + owner uses + membership queries + retained
anchors), with first-scan characters, canonical integer comparisons and managed
ordered lookup/page I/O stated separately. There is no per-owner position copy,
invalid-list replay, BigInteger ordinal increment or membership-miss insertion.
Input/key/storage lifetimes must match. Calls and callbacks are sequential and
non-reentrant. Operational/report/source failures poison the inspector; scratch
closure preserves primary/suppressed failures and leaves borrowed input/keys owned
by the caller.

Eight registered contracts cover natural ordinal boundaries/huge integers, bounded
cached reads, exact open/closed union/order,96independent random position lists,
empty context keys, entry-owned membership, five geometric bad-list scales through
4096rows/8193owner uses with two retained diagnostics and one source cursor, scratch
interruptions, source/cardinality/cursor failures, all report steps, reentrancy,
construction denial and combined cleanup. Map-backed test ports establish semantic
and primitive-work laws only. Managed paged ports, complete admission and production
CLI integration remain separately qualified frontiers.
